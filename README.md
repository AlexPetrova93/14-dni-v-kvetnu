# Malíř

A game from the cycle "14 Days in May" which was a part of an exhibition for the Jindřich Chalupecký Award. It is a game about a lonesome painter living on an abandoned island; the player gets glimpses into the painter's life through a series of paintings the player paints.
Link to the game: [https://nofunkolektiv.itch.io/posun-pleso](https://nofunkolektiv.itch.io/malir)
